# GUI 重做藍圖

2026-11-22。擁有者實際安裝使用後認為 OEP 畫面雜亂，不如 AEP，且在畫面與 AEP 原有功能未完善前難以比較測試。決定以擁有者提供的最新 AEP 截圖為版型依據重做前端外殼。功能邏輯、API 與後端不變。AEP 的程式、圖示、文字與資料不複製，OEP 獨立製作。

## 版型依據（擁有者說明）

畫面分成三大部分：

1. **功能欄（最左）**：分「主功能」「Sessions」「Agents」三個區塊，每個區塊可各自展開與收合。頂端有助理頭像、名稱與一句簡介。
2. **功能內容顯示區（中間）**：隨左側選擇切換。選設定顯示設定內容；選 session 顯示對話；選知識庫顯示資料操作資訊。
3. **附加資料顯示區（右側，按需出現）**：在中間區操作所產生的內容才在此開啟，例如點選對話中產生的 md、html、excel、png、txt 檔案，或在知識庫點選中間區的 AI session。以分頁呈現，每頁可關閉，並有「在瀏覽器開啟」「下載」。沒有內容時整區不顯示，中間區佔滿。

另有：頂列放模型來源、狀態與身分資訊；輸入框內含附件、模型選擇（顯示「設定預設」與生效時機）、送出；輸入框下方一行固定說明。

## 診斷（OEP 現況）

- 右側面板常駐，內容多半是空的，卻佔三分之一寬度。應改為點選產生物才出現。
- 左欄把導覽、助理選單、搜尋、專案分組、模型名、審核清單與設定全塞在一起，沒有分組與收合。
- 殘留示範文字：「BI 審核示範」「模型 synthetic-browser」。
- 技術名詞外露：產物、差異、即時進度、快捷鍵、會話模型。
- 連線狀態、停止服務、設定入口位置分散。
- 先前驗收以功能對照表為準，沒有以日常使用順手度驗收，截圖也只用合成資料。

## OEP 新版型

**左欄（固定寬度，可捲動）**
- 頂端：助理頭像、名稱、一句簡介。
- 區塊「主功能」（可收合）：對話、知識庫、排程與工作、審核、能力、記憶、設定。每項一行，圖示加名稱。尚未實作的項目不顯示，不放灰色假入口。
- 區塊「會話」（可收合，顯示數量）：依專案分組，含搜尋、新增、改名、刪除。
- 區塊「助理」（可收合，顯示數量）：已設定的助理與其連結（例如 Telegram bot 名稱）。
- 收合狀態在重開後保留。

**中間內容區（單欄）**
- 頂列：模型來源與狀態；右側為身分與連線資訊（小字）。停止服務收進選單。
- 對話：訊息區加大型輸入框。輸入框內：附件、模型選擇（含「設定預設」與「下一則訊息生效」說明）、送出／停止。下方固定一行說明。
- 設定：整頁，頁內左側子導覽（助理、外觀、模型、限制、整合、輸入、專案、MCP、關於），不再用側欄手風琴。
- 知識庫：整頁，保留概覽、問答、品質、建置四個分頁。
- 排程與工作、審核：各自整頁。

**右側附加區（按需）**
- 點選訊息中的檔案、附件、表格預覽、差異、筆記時開啟，以分頁顯示，可關閉單頁或整區。
- 預覽沿用既有 md、html、excel、png、txt、pdf 與差異能力；在知識庫則可開啟 AI session。
- 窄螢幕改為全幅覆蓋，返回鍵回到中間區。

**文字與狀態**
- 所有面向使用者的字串改為日常用語；技術名詞只放「進階」摺疊內。
- 移除所有示範字串與合成殘留。
- 空狀態只顯示輸入框與簡短提示。

## 驗收

- 以擁有者真實使用情境的截圖（只存本機，不入庫）與合成資料截圖並列，由擁有者逐頁確認。
- 既有 Chromium、網頁、Excel、知識庫、Telegram、MCP 測試維持通過。只允許改動定位器與版面斷言，不得刪斷言或放寬條件。
- 寬、窄兩種視窗，亮、暗兩種主題。
- 鍵盤可達所有導覽、收合區塊與右側分頁；開關右側區時保留焦點。
- 自動檢查：頁面沒有示範字串，也沒有未翻譯的技術名詞白名單外字樣。

## 分步（每步獨立可驗收）

1. 外殼：三區版型、左欄三區塊與收合、右側按需開啟。對話與既有功能全部搬入新外殼，行為不變。
2. 設定整頁與子導覽。
3. 知識庫、排程與工作、審核整頁與右側 AI session 開啟。
4. 文字與用語整理、示範字串清除、深色與窄螢幕調整。
5. 新增缺口功能（能力與技能管理、記憶、聯絡人、名片），放進新外殼。

## 不在範圍

後端、資料格式、API、安全邊界、Telegram、發行腳本。

## 擁有者確認（2026-11-22）

擁有者指示：依上述三區邏輯重構所有功能的 GUI，不只外殼。因此分步 1 至 5 全部納入，依序執行，每步通過完整回歸並經擁有者看截圖確認後才進下一步。每個既有功能（對話、檔案預覽、設定各區、MCP、知識庫四個分頁、建置與審核、排程與工作、Telegram、語音、斜線指令、訊息操作、筆記）都要有明確的新位置，並以對照表記錄在 `docs/GUI_LAYOUT.md`，不得有功能變得無法到達。
