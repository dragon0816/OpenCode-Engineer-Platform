# GUI 重做藍圖（草案，待擁有者確認）

2026-11-22。擁有者實際安裝使用後認為 OEP 畫面雜亂，不如 AEP，且在畫面與 AEP 原有功能未完善前難以比較測試。決定以 AEP 的版型為準重做前端外殼。功能邏輯、API 與後端不變。

## 診斷（OEP 現況）

- 三欄同時顯示：左欄、對話、右側「檔案與產物／工作／差異／筆記」。多數時間右欄是空的，卻佔三分之一寬度。
- 左欄塞了導覽、助理選單、搜尋、專案分組、模型名、審核清單與設定，沒有層次。
- 殘留示範用文字：「BI 審核示範」「模型 synthetic-browser」。
- 技術名詞外露：產物、差異、即時進度、快捷鍵、會話模型。
- 連線狀態、停止服務、設定都在不同位置，沒有固定位置。
- 先前驗收以功能對照表為準，沒有以「日常使用是否順手」驗收，截圖也只用合成資料。

## AEP 版型（只描述版面，不複製程式碼、文字或資料）

- 左側單一窄欄：產品名、一排扁平導覽（新會話、能力、設定、排程、知識、工作、審核、記憶），下方是會話清單與搜尋。
- 主區只有一欄：頂列放模型選擇與狀態，中間是訊息，底部是大型輸入框。
- 輸入框內含附件、模型、送出；一行說明文字；沒有常駐右欄。
- 每個導覽項目是主區的一整頁，不是疊在側欄裡的區塊。

## OEP 新版型

1. **左欄**（固定寬度）：OEP 名稱、`＋ 新會話`（主按鈕）、導覽（對話、知識庫、排程、審核、能力、設定，各一行圖示加名稱），以下是會話清單（依專案分組，可收合）與搜尋。連線狀態縮成名稱旁的小圓點。
2. **主區單欄**：
   - 頂列：會話標題（可改名）、模型選擇、`檔案 (n)` 按鈕。
   - 訊息區。
   - 輸入框：附件、`產生 Excel` 晶片、送出。快捷鍵收進 `?` 浮層。
3. **右側抽屜**：預設隱藏。按 `檔案 (n)` 或產生新檔案時才滑出，內含檔案、產出、差異、筆記四個分頁。窄螢幕改為全幅覆蓋。
4. **設定**：主區整頁，左側子導覽（助理、外觀、模型、限制、整合、輸入、專案、MCP、關於），不再使用側欄手風琴。
5. **知識庫、排程、審核**：各自為主區整頁。知識庫保留四個分頁，其餘次要操作收進「更多」選單。
6. **文字**：所有面向使用者的字串改為日常用語；技術名詞只出現在「進階」摺疊內。移除所有示範字串。
7. **空狀態**：對話首頁顯示三個建議動作與輸入框，不顯示說明長文。

## 驗收

- 以擁有者真實使用情境截圖（本機資料，不入庫）與合成資料截圖並列，擁有者逐頁確認。
- 既有 Chromium、網頁、Excel、知識庫、Telegram、MCP 測試全部維持通過；僅允許改動定位器與版面斷言，不得刪斷言。
- 寬、窄兩種視窗、亮、暗兩種主題。
- 鍵盤操作可達所有導覽與抽屜；抽屜開合保留焦點。
- 無示範字串、無技術名詞外露的自動檢查。

## 不在這次範圍

後端、資料格式、API、安全邊界、Telegram、發行腳本。功能缺口（能力與技能管理、記憶、聯絡人、名片）在版型確認後排入新版型。
