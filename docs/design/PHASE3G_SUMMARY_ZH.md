# Phase 3G 知識庫簡介

外掛是用來建立知識庫的工具。發布後的知識庫是成品，助理可以用它回答問題並指出資料來源。

## 擁有者會怎麼用

1. 在「能力」安裝 OEP 團隊簽章的 BI Knowledge 外掛，左側「主功能」就會出現 BI 頁。
2. 從 BI 頁加入檔案，或從既有的 BI 匯出資料夾建立新知識庫。畫面會顯示轉檔、整理與檢查進度。
3. 在「審核」檢查卡片與證據，先核准，再發布。需要時可以切回以前的發布版本。
4. 到助理設定勾選已發布的知識庫。回到對話試問，點引用即可核對來源。
5. 移除 BI 外掛後，助理仍能用已發布的知識庫。未完成的建置先保留，重裝相容版本可接著處理。

## 先做好哪些事

- 首版先把本機的安裝、建庫、發布、助理問答接通。發布版可匯出，在另一個 OEP 安裝後提供問答。
- 既有 BI 知識與助理設定保留。日後接上公司 Share Platform，便能從平台取得發布版。
- 用合成資料驗證整條流程。擁有者提供的樣本留在本機，內容品質與試問題目由 BD／PM／AE 負責。
- Knowledge Wiki 是後續的建置外掛，沿用同一套發布方式。

待確認的是簽章保管人與首版交付方式、正式試問所用的 Gateway 模型及題目負責人，以及首批平台分享的對象。
