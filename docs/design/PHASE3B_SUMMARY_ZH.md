# 多助理與交辦｜擁有者摘要

## 你會看到什麼

- 左欄的「助理」會列出主助理、內建的「BI 資料處理」及你新增的專職助理。按「＋」可設定名稱、模型、可用的知識庫和 Telegram bot。
- 主助理是工作台的預設對話入口，並沿用原 Main bot。主要工作區和獨立工作區都歸主助理，原本的會話、檔案和紀錄會保留。新助理各有自己的工作資料夾。
- 「設定」提供 bot 對應表。每個 bot 只綁一個助理，既有 Main 和 BI bot 沿用目前的設定。每個助理可用繁中或英文回覆 Telegram。
- 第二階段會開放交辦。對主助理說「把這份檔案做成 BI 卡片」時，它會交給「BI 資料處理」。主助理先回覆已交辦，你可繼續對話。完成時，原對話會收到摘要及結果，點一下可在右側看完整紀錄。
- 你也可以直接和專職助理對話，例如查 BI 收件進度或補件。主助理看不到這些對話。你授權共享的已發布內容仍可供助理查詢。

## BI 如何送審

從 BI bot 傳來的連結或檔案會先收進收件匣。資料不足時會請你補件。資料齊全後，「審核」頁會出現標有「BI 資料處理」的候選卡片。你先核准，再發布，卡片才可搜尋及問答。原接收入口會收到發布通知。現有收件、待審項目和已發布版本會一起保留。

## 需要你決定的三件事

1. **舊外部工具要何時恢復供助理使用？** 建議保留設定，先暫停可執行本機程式或連進私人網路的工具，通過檔案隔離驗證後再開放。若升級當天就要繼續用，需先完成這部分隔離。
2. **預設交辦額度夠不夠？** 建議每則訊息最多交辦三件，每件最多執行 90 秒及四次模型請求，排隊最多十分鐘。
3. **日後的定時工作預設通知誰？** 建議先回報主助理，由它通知你。每筆排程仍可指定直接送到專職助理的通道，或只存檔。
