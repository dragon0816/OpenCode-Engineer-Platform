# 外部程式開發幫手｜擁有者摘要

OEP 可以把指定的程式修改交給 Claude Code 或 Codex。兩者各自預設關閉，使用時由你登入自己的帳號。Copilot 暫緩。

## 哪些資料會送出

- 只有你明確標為公開、這次選取的任務和資料才會傳給所選服務。未分級或機密的資料會擋下。
- 檔案改過、引用來源變了，或內容來自無法查明的來源，都要先處理，才能送出。
- 你可在「設定 > 外部幫手」開啟其中一個。預設每次送出前都先顯示將傳送的資料。使用可能耗用你的訂閱額度或產生費用。
- 停止可以中斷後續傳送，已傳給供應商的資料無法收回。

## 完成後看哪裡

- 幫手只改一份臨時副本，原始檔由你掌握。結果會回到主助理的原對話。
- 在右側查看哪些行和檔案變了。你可以下載差異或變更後的檔案，審閱後自行套用。
- OEP 不接收你的供應商密碼，也不把 OEP 的金鑰、其他助理的資料或聊天紀錄交給幫手。

## 上線前需確認

- 建議接受一次性的 Windows 隔離設定。若設定無法驗證，幫手保持停用。
- 建議保留逐次確認為預設，並讓你決定是否關閉額外確認。每次仍須先選取資料並通過公開檢查。
- 建議首版由你下載後手動套用。之後有需要再考慮工作台內套用。
- Claude Code 先確認供應商允許的商業安排和自有帳號方案，再開放啟用。兩套幫手各自驗收。

自動測試使用假幫手和合成資料。實際帳號檢查可另在測試環境用全公開的範例執行。
