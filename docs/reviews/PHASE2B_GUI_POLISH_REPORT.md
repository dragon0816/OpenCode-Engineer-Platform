# Phase 2b 工作台介面整理

2026-11-22（Asia/Taipei）。基準為 `main` 的 `8111256`，交付分支為 `phase-2b/gui-polish`。環境為 Windows 11 x64、Node 24.14.1、PowerShell 7.6.10。各驗收指令使用獨立的暫存 `OEP_DATA_DIR`。Excel 指令使用既有 openpyxl 虛擬環境的程序層級 PATH 與 `OEP_PYTHON`。MCP 與備份測試建立各自隨機命名的合成憑證項目，並在結束時清除。 [定稿對照與樣張](../GUI_LAYOUT.md)

## 已交付

- 統一各頁、選單、對話框和狀態的繁中用語。檔案校驗碼、工具執行細節、外部工具的連線診斷收在「進階」。保留可手動載入及移除的範例知識庫，畫面使用「範例知識庫」與「標準題集」，測試用的模型代號和知識庫識別碼由既有介面內部使用。
- 淺色、深色和系統主題共用色彩變數及瀏覽器配色。文字、控制項邊界、鍵盤焦點、停用狀態、程式碼、表格、預覽分頁及變更對照使用對應的色彩。
- 800 px 以下以「功能導覽」開啟功能欄，設定改用原生分類選單。900 px 以下的附加資料採全幅覆蓋。「返回對話」、「返回頁面」及 Esc 可關閉，並將焦點交回開啟控制項。縮短視窗時可操作輸入欄和送出按鈕。
- 共用頁首、間距、文字大小、按鈕與焦點樣式。頂列及會話列右側收納「更多」選項。Tab 可離開會話選單，窄版的附加資料開啟時可用 Tab 循環。取消會話刪除或關閉外部工具編輯器時還原焦點。
- 設定與功能對照表定稿，共 56 列。工作台 Chromium 驗收涵蓋設定，知識庫與外部工具 Chromium 驗收使用各自的合成資料檢查會隨狀態出現的控制項。 [控制項對照](../GUI_LAYOUT.md#設定控制項對照定稿)
- 重拍 192 張樣張。48 個畫面各有 1440 × 900 和 390 × 844、淺色和深色版本。驗證全部 PNG 尺寸並檢視縮圖及主要頁面。畫面中的資料、路徑及內容取自合成測試。 [樣張](../GUI_LAYOUT.md#版面樣張)

## 測試調整與理由

| 檔案 | 調整與理由 |
|---|---|
| `forbidden-shell-text.ts` | 逐一檢查可見文字、選項名稱、替代文字、標題、預留文字、無障礙名稱與描述。禁止字串也檢查展開後的進階內容，技術用語只在進階內容放行。淺色與深色各跑一次。原生對話框用測試替身讀取實際傳入的提示並取消操作。 |
| `gui-contrast.ts` | 讀取瀏覽器實際套用的文字、背景、邊框及焦點色。文字須至少 4.5:1，控制項邊框與焦點須至少 3:1。兩種主題各自檢查。 |
| `gui-mapping.ts` | 將對照表各列連到 Chromium 驗收，檢查屬於各群組的列都有對應檢查。用實際來源連結核對下載控制項，來源版本在可提供版本的問答引用中驗證。 |
| `web-browser.test.ts` | 增加每頁及知識庫各頁籤、設定各分類的水平溢出檢查，尺寸為 390 × 844、768 × 1024、1440 × 900。另測 390 × 420 的輸入與送出、窄版觸控目標、全幅附加資料及鍵盤還原焦點。保留原有設定、訊息、下載、比較、取消、跨專案及防洩漏斷言。校驗碼與移除附件的定位隨「進階」及操作列位置更新。更新外部工具、知識庫工作與聽寫錯誤的字面比對，以核對新版文字。回合上限提示加測重送前的處理方式。重新載入等待新文件及「已連線」。樣張開關只接受合成資料，擷取後還原安全測試用的文字。 |
| `knowledge.test.ts` | 在原有匯入、問答、品質、建置、排程、收件與審核流程各階段檢查定稿對照、雙主題用語和對比。樣張使用 1440 × 900 及 390 × 844。重新載入等待新文件及「已連線」，並保留就緒與頁籤回復斷言。原有 200 ms HTTP 上限維持。 |
| `custom-mcp-browser.ts` | 增加外部工具清單、新增及遠端編輯器、認證欄位、連線結果、套用時機及移除確認的對照或文案檢查。HTTPS 驗證訊息移至「進階」，原有驗證比對隨之移動。原有工具權限、程序清理及憑證查漏斷言保留。擷取兩種主題和新尺寸。 |

## 尚未完成

- 執行中的 OEP 保留運作。Web HTTP、真模型 Excel、安裝、升級及備份還原仍需由擁有者在可使用執行及維護鎖的環境驗收。
- 擁有者尚未逐頁審閱樣張或在實際工作資料上確認。Chromium 驗證使用合成資料、縮短視窗模擬鍵盤占用空間，以及模擬聽寫結果。實機觸控鍵盤與麥克風待驗。
- 雙主題文字與對比檢查涵蓋測試可重現的畫面及狀態。外部服務、瀏覽器原生選檔介面及使用者載入的文件或訊息可帶有自己的文字或配色。
