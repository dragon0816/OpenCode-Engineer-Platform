# Phase 2b 設定整頁驗收

2026-11-22（Asia/Taipei）。分支 `phase-2b/gui-settings-page`，起點 `6e330ac`。驗收環境為 Windows 11 x64、Node 24.14.1、PowerShell 7.6.10。各指令使用獨立的暫存資料目錄，Excel 驗證使用暫存虛擬環境的 Python 與 openpyxl 3.1.5。 [控制項對照及合成樣張](../GUI_LAYOUT.md#設定)

## 交付

1. 中央區域的設定整頁和左側分類，包含助理、外觀、模型、回合限制。儲存結果顯示在操作旁。
2. 專案與資料夾、整合、輸入、執行環境及關於的獨立分類。整合頁重用既有 `GET /api/jobs` 回應的兩個設定旗標，分別顯示 Telegram 助理與 BI 機器人的狀態。
3. MCP 分類保留內建知識庫、伺服器編輯、憑證輸入、工具管理、連線測試和重新啟動提示。
4. 完整控制項位置對照、可見文字檢查、760 px 以下的原生分類選單，以及每個瀏覽器來源的分類記憶。返回對話與主功能切換沿用工作台的導覽。
5. Chromium 回歸覆蓋十個分類、鍵盤操作、版面、可見文字、設定持久化及條件顯示的控制項。
6. 40 張合成樣張，每個分類各有淺色與深色、寬版 1200 × 960 與窄版 390 × 960。24 張既有 `settings-*` 樣張重拍。專案及資料位置使用合成顯示路徑。
7. 更新本報告及任務清單。

助理指示沿用既有的偏好設定欄位，進階說明交代它與 `soul.md` 的用途關係。模型頁只讀取既有憑證設定旗標。MCP 密碼欄仍透過既有的寫入操作提交。此次修改僅涉及前端、測試及文件。
