# Phase 2b 知識庫、排程與工作、審核驗收

2026-11-22（Asia/Taipei）。分支 `phase-2b/gui-knowledge-jobs-pages` 從 `4aaa901` 開始。驗收使用 Windows 11 x64、Node 24.14.1、PowerShell 7.6.10。各指令使用獨立暫存資料目錄。Excel 驗證的 Python 與 openpyxl 使用既有的暫存虛擬環境。 [控制項對照與樣張](../GUI_LAYOUT.md#知識庫排程與工作審核)

## 交付

1. 知識庫頁首集中已發布的庫選單及搜尋狀態。概覽、問答、品質、建置每次顯示一頁，可用滑鼠、方向鍵、Home 和 End 切換。問答的輸入框位於頁末。
2. 建置保留發布匯入、手動卡片與文章草稿、來源選取和模型提案。卡片、答案引用、搜尋結果來源、建置來源文字、已送審草稿和模型提案共用外殼的附加資料分頁。既有模型提案回傳待審草稿，因此右側直接開啟該筆審核及引文。產品目前沒有獨立的模型提案會話。
3. 排程與工作呈現狀態、下次執行和各列操作。詳細資料、執行紀錄、新增與編輯排程、Telegram 收件與通知紀錄在右側開啟。工作與通知狀態沿用既有台帳回應，通知重送仍需人工確認。
4. 保留獨立的「審核」主功能，因為清單同時涵蓋各卡片與文章知識庫，選取中的發布庫不決定審核範圍。待處理清單包含待審核及核准待發布的草稿。右側顯示變更與來源引文，也保留編修、比較、草稿搜尋、拒絕、捨棄、核准、另一步發布與版本操作。
5. 控制項與狀態已記錄在版面對照表。進階設定、版本識別資料、品質門檻與版本回復收進揭露區。Esc 可關閉「更多」或附加資料，附加資料關閉後焦點回到開啟控制項。重新載入後，重新進入知識庫會恢復上次使用且仍可用的知識庫及頁籤。窄版預覽使用既有全幅覆蓋。
6. 擴充 Chromium 的頁面、鍵盤、引用、排程及兩階段審核回歸。進階以外的可見文字檢查涵蓋三個中央頁面、知識庫四個分頁與附加資料中的主要畫面。
7. 共 36 張合成 PNG。四個知識庫頁籤和卡片預覽共重拍 20 張既有 `slice3a-*` 樣張。排程清單與執行紀錄、審核清單與單筆草稿共新增 16 張。每種畫面均有淺色與深色、1360 × 900 寬版和 420 × 900 窄版。
8. 更新本報告及任務清單。

下次執行時間以現有排程時區、狀態和最近的執行紀錄在前端計算，預估會略過夏令時間跳過的時刻及已建立的同一筆執行。已納入的來源內容與版本資訊使用既有 API。範本保留原有資料結構，草稿初始內容取用已載入來源或留白。這次無新增端點或資料格式。
