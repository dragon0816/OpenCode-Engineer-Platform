# Phase 2b GUI 外殼第二版驗收

2026-11-22（Asia/Taipei），Windows 11 x64、Node 24.14.1、PowerShell 7，分支 `phase-2b/gui-shell-v2`，起點 `859af34`。測試各自使用新建的短路徑暫存資料夾，Excel 驗證使用暫存虛擬環境的 Python 與 openpyxl 3.1.5。 [新版版面與 16 張樣張](../GUI_LAYOUT.md)

## 交付項目

1. 三區工作台。功能欄顯示既有助理設定、可獨立收合的主功能、專案會話及助理選擇。審核捷徑開啟知識庫的既有審核介面。設定、知識庫、排程與工作使用中央區域。
2. 按需附加區。對話中的附件與產出可直接開啟分頁，工作、變更對照與筆記可由選單開啟。每個分頁可關閉，Esc 關閉整區並還原焦點。窄版使用全幅覆蓋與「返回對話」。
3. 頂列集中顯示模型、來源、對話狀態、身分及連線。停止服務放進工作台選單。大型輸入框提供附件、模型、生效時機、送出與停止處理。
4. 移除舊審核示範標示，調整測試模型的顯示名稱及繁中操作用語。保留知識庫的範例資料載入及移除。
5. 擴充 Chromium 鍵盤、重新載入、預覽及可見文字驗證。
6. 以專案的合成測試資料重拍 156 張既有樣張，另加 4 張已驗證 Excel 產出分頁樣張。四個指定畫面均有寬／窄、淺／深版本，PNG 檔頭與尺寸共檢查 160 張。
7. 更新版面規格、任務狀態及本報告。
